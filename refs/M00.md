## Primary teaching references

### M00-R01 — Polygon Mesh Processing
- Authors: Mario Botsch, Leif Kobbelt, Mark Pauly, Pierre Alliez, Bruno Lévy
- Role: Primary / Engineering
- Use in M00: mesh representation, data structures, traditional geometry-processing viewpoint
- Status: identified
- User copy requested: **yes, high priority**
- Reading rule: do not read cover-to-cover for M00; select the mesh representation/data structure parts and return later for classical algorithms.

### M00-R02 — Using Generic Programming for Designing a Data Structure for Polyhedral Surfaces
- Author: Lutz Kettner
- Journal: Computational Geometry 13(1), 1999, 65–90
- Role: Primary / design-history bridge
- Use in M00: understand why a polyhedral-surface data structure is a mathematical/software design problem rather than merely a container choice
- Status: openly findable online; stable project copy still desirable
- User copy requested: **yes, high priority**

### M00-R03 — Discrete Differential Geometry: An Applied Introduction
- Authors: Keenan Crane et al.
- Role: Primary later / perspective now
- Use in M00: discrete-surface viewpoint and bridge toward M02–M06
- Status: public versions exist
- User copy requested: **optional but useful if we want a fixed course baseline**

## Engineering references — official documentation

### M00-E01 — libigl tutorial
- URL: https://libigl.github.io/tutorial/
- Focus: `V,F` matrix representation, Eigen-oriented processing style
- Why: canonical example of deliberately avoiding a heavy mesh object for many geometry-processing tasks

### M00-E02 — geometry-central SurfaceMesh basics/internals
- URLs:
  - https://geometry-central.net/surface/surface_mesh/basics/
  - https://geometry-central.net/surface/surface_mesh/internals/
  - https://geometry-central.net/surface/geometry/geometry/
- Focus: halfedge navigation, dense/indexed storage, connectivity-vs-geometry separation, manifold/general surface distinction
- Why: especially close to the mathematical taste of this course

### M00-E03 — CGAL Surface_mesh
- URL: https://doc.cgal.org/latest/Surface_mesh/index.html
- Focus: index-based halfedge, descriptors, runtime property maps, BGL graph concepts, deletion/garbage collection
- Why: mature generic-library viewpoint

### M00-E04 — OpenMesh documentation
- URL: https://www.graphics.rwth-aachen.de/media/openmesh_static/Documentations/OpenMesh-8.1-Documentation/index.html
- Focus: halfedge structure, handles, iterators/circulators, custom properties, local topology operations
- Why: classic engineering reference for reusable polygon-mesh data structures

## Optional / historical side roads

The following should not block M00, but may become side notes or library-study material:

- directed-edge representations;
- corner-table representations;
- quad-edge and related primal/dual topological representations;
- early halfedge / polyhedral-surface representations;
- data structures for general cell complexes rather than manifold surface meshes.

Do not expand all of these into the main Note unless user feedback shows that representation theory itself should become a larger branch.

## Requested references for the user

Please prioritize, when convenient:

1. **Polygon Mesh Processing** — full book/ebook/PDF.
2. **Lutz Kettner (1999), Using Generic Programming for Designing a Data Structure for Polyhedral Surfaces** — stable full PDF in the project.
3. If already available: any serious OpenMesh / CGAL / geometry-central design paper or course note which explains *why* the data structure was designed that way, not merely API usage.
4. Optional: a fixed version of **Discrete Differential Geometry: An Applied Introduction** for the course archive.

The same request list is repeated at the end of `M00-N01` so it remains visible during reading.
