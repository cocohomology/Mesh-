# Tasks

## Status conventions

- `TODO`：尚未开始
- `DOING`：当前进行中
- `BLOCKED`：被依赖或资料阻塞
- `DONE`：完成
- `DEFERRED`：明确延后

## Task handoff template

新增任务尽量写成：

```markdown
- [ ] 任务名称
  - Why: 为什么现在要做
  - Input: 依赖哪些文件/资料
  - Output: 需要产生什么文件或结论
  - Done when: 完成标准
```
