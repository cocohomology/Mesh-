# Progress

## Current phase

**Phase 0 — Course infrastructure and syllabus architecture**

当前正在建立课程运行机制与课程大纲系统，尚未开始正式教学 Note。

## Current focus

建立一套不依赖聊天上下文的课程推进系统，包括：

- 课程运行协议；
- 跨聊天交接；
- 进度与任务追踪；
- 关键决策日志；
- 用户反馈闭环；
- 动态大纲；
- Note 系统；
- Discussion 系统；
- Reference 系统。

## What is now settled

- 本课程不是传统“网格算法大全”。
- 课程追求数学结构与网格算法之间的强连接。
- 数学学习不与工程割裂。
- 核心算法需要分析：对象、假设、数学结构、核心定理、失效机制与推广。
- 课程大纲允许动态调整。
- 仓库文档必须足以让新聊天独立接手。
- Note 应是教学式讲义，而不是聊天摘要。

## What remains open

当前仍未确定、后续需要逐步形成：

- 正式课程模块的完整次序；
- 第一篇 Note 的主题与切入方式；
- TeX/Markdown 的具体分工与构建方式；
- 实验代码是否进入本仓库或未来拆分；
- 参考教材、论文与实现库的正式清单；
- 课程阶段性验收方式。

## User feedback to preserve

- 希望掌握网格算法，但不是传统工程师式的“会写会调”。
- 希望算法背后建立整套数学理论。
- 数学上至少关注拓扑、几何、分析三大层面，代数结构融入其中而非孤立教学。
- 重要算法应能从宏观结构解释其成立范围与失效原因，例如 Delaunay triangulation。
- 传统 mesh processing 可作为工程参照，但不应成为课程唯一主线。
- 整个课程必须能够跨聊天持续推进。
