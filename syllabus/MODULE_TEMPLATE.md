# Module Template

每个正式模块建议使用以下模板。可按需要删改，但应保留“数学结构—算法—失效—工程意义”这一核心链条。

```markdown
# Module XX — Title

## Why now

## Prerequisites

## Mathematical objects

## Core structures

## Central questions

## Key theorems / principles

## Algorithms

## Failure modes and boundary cases

## Generalizations

## Engineering meaning

## Notes planned

## Exercises / derivations

## Experiments / implementations

## References

## Open questions

## Exit criteria
```

## Module status

建议在标题附近标注：

- `planned`
- `active`
- `paused`
- `completed-stage`

`completed-stage` 表示阶段完成，不意味着主题永久封闭。
